# 💻 TeleDesk — Remote PC Control via Telegram

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![OS](https://img.shields.io/badge/OS-Windows-green.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**TeleDesk** — это легкое портативное приложение с графическим интерфейсом (GUI) на Python и Tkinter для безопасного удаленного управления ПК на базе Windows через вашего собственного Telegram-бота.

Скрипт превращает бота в полноценный пульт дистанционного управления: от снятия скриншотов и работы с веб-камерой до управления файлами, процессами, питанием и физической блокировки экрана.

---

✨ Основные возможности
📺 Мониторинг и Захват
Скриншоты: Получение снимка любого из подключенных экранов в один клик.

Веб-камера: Быстрое фото с подключенной веб-камеры.

Запись видео: Запись коротких видеороликов с экрана (5, 10, 15, 30 секунд).

📂 Файловый менеджер (FTP)
Удобная навигация по дискам и папкам с помощью Inline-кнопок в Telegram.

Скачивание файлов с ПК прямо в чат.

Ограничение доступа через белые (allowed_dirs) и черные (blocked_dirs) списки папок.

🛡️ Безопасность и Приватность
Single Instance Lock: Блокировка повторного запуска той же копии программы через системный Mutex.

Авторизация: Жесткая привязка к Admin ID + опциональная защита паролем прямо в чате.

Экран-Штора (Blackout Screen): Мгновенное затемнение и блокировка экрана черной «шторой» для защиты от посторонних глаз.

Скрытие данных: Маскирование токена и ID в GUI, поддержка Ctrl+V при любой раскладке клавиатуры.

⚡ Управление питанием и системой
Выключение, перезагрузка, переключение в спящий режим.

Установка таймеров сна (15, 30, 60+ минут).

Отключение физического монитора и сворачивание всех окон (Win+D).

🎵 Медиапульт и Команды
Регулировка системной громкости и управление плеером (Play/Pause/Next/Prev).

Синтез речи на ПК через команды (/say <текст>).

Вывод всплывающих окон над всеми программами (/msg Заголовок | Текст).

Чтение и запись в системный буфер обмена (/setcb <текст>).

Просмотр топ-10 процессов по памяти и их удаленное завершение (/close <имя>).

Быстрый запуск выбранных программ, ярлыков и сайтов.

🔋 Трей и Автозапуск
Сворачивание приложения в системный трей (рядом с часами).

Тихий автозапуск вместе с Windows (с параметром --minimized).

🔒 Безопасность и антивирусы (False Positives)
При самостоятельной сборке проекта в файл .exe через PyInstaller некоторые антивирусы (включая Windows Defender) могут выдавать предупреждения. Это стандартное поведение для новых или нескомпилированных коммерчески исполняемых файлов без платной цифровой подписи.

100% Открытый код: Все исходники находятся перед вами — здесь нет скрытых серверов, майнеров или отправки данных третьим лицам.

Локальное хранение: Файл config.json с вашим токеном находится только на вашем ПК.

Прямое соединение: Приложение общается исключительно с официальным сервером api.telegram.org.

🛠️ Установка и запуск из исходного кода
1. Клонирование репозитория
git clone ([https://github.com/cybercraftt/TeleDesk.git](https://github.com/cybercraftt/TeleDesk-Remote-PC-Control-via-Telegram))
cd TeleDesk

2. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10+.
pip install -r requirements.txt

3. Запуск
python TeleDesk.py

📦 Сборка в .exe (PyInstaller)
Для создания автономного .exe файла, которому не нужен установленный Python:

Установите упаковщик:

pip install pyinstaller
Скомпилируйте проект:

Рекомендуемый вариант (Сборка в папку — запуск быстрее, меньше вопросов от антивируса):

pyinstaller --noconfirm --onedir --windowed --add-data "icon.ico;." --icon="icon.ico" TeleDesk.py
Вариант в один файл:

pyinstaller --noconfirm --onefile --windowed --add-data "icon.ico;." --icon="icon.ico" TeleDesk.py
Заберите готовый результат из папки dist/.
